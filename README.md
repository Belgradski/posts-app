# React JSONPlaceholder Explorer
React-приложение для работы с API JSONPlaceholder.

## ✨ Функциональность

- Список постов с фильтрацией по длине заголовка
- Детальная страница поста с комментариями
- Профили пользователей (посты, альбомы, задачи)
- Галерея фотографий
- Тёмная/светлая тема
- Кэширование данных через RTK Query


📦 Установка и запуск:

npm install
npm run dev

## Структура проекта(FSD):
src/
├── app/          # Инициализация, store, роутинг
├── pages/        # Страницы
├── widgets/      # UI-блоки (UserTabs, CommentList)
├── features/     # Фичи (фильтрация, тема)
├── entities/     # Сущности (post, user, album, comment, todo)
└── shared/       # Переиспользуемые компоненты, утилиты
